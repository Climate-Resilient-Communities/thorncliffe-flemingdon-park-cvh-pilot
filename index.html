Opening the files. Each app is one self-contained HTML file: open it in Chrome, Edge, Firefox or Safari, straight from this folder. No server or install needed.

What needs the internet. Fonts (Public Sans, Noto) and the Leaflet map library load online. Offline, the screens use system fonts and the map falls back to the drawn map. Everything else works offline.

Sessions. Actions in one app (for example, the Hub publishing an alert) reach the other apps open in the same browser, as on the canvas. Use "Clear the session" under Test to start again.
